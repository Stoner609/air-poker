# Air Poker Roadmap

這份文件記錄 Air Poker 接下來的開發方向。功能會依序完成，不代表所有項目都已經排定發佈日期。

## 開發原則

先讓第一次接觸的玩家能理解並完成一場遊戲，再擴充連線、手機和更多遊戲內容。新功能不應該取代 Air Poker 的核心：目標數字解題、共用牌池和 BIOS 下注。

## 第一階段：新手體驗

- [ ] 分段互動教學：選數字、組牌、鎖定、下注與結算
- [ ] 固定腳本對手的完整教學對局
- [ ] 教學可以跳過，也可以從選單重新遊玩
- [ ] 提示由玩家主動開啟，並可在設定中調整
- [ ] 教學完成後直接進入標準五局對局

完成標準：不熟悉規則的玩家能在沒有口頭協助下完成一場對局。

## 第二階段：兩人連線對戰

- [ ] 使用 WebSocket 建立即時連線
- [ ] 透過房間碼加入對局，不開放公開房間列表
- [ ] 房主建立房間，雙方準備後才開始
- [ ] 第一版只支援標準五局對局
- [ ] 由伺服器保存狀態並驗證所有遊戲操作
- [ ] 玩家進入房間時輸入暱稱，重複暱稱自動加入識別碼
- [ ] 玩家斷線時立即判定敗北
- [ ] 對局結束後提供重播與匯出
- [ ] 再戰時沿用原房間，雙方重新準備
- [ ] 房間碼建立後 10 分鐘內有效
- [ ] 房主離開等待室時關閉房間

伺服器只在房間存活期間暫存對局資料，不長期保存重播。玩家若要保留紀錄，應自行匯出。

## 第三階段：手機版

- [ ] 支援手機瀏覽器的響應式 Web 介面
- [ ] 以橫向畫面作為主要設計方向
- [ ] 支援觸控選牌、拖曳或替代操作方式
- [ ] 保留桌面版完整規則與功能
- [ ] 確認倒數、牌池、BIOS 和下注資訊在小螢幕上仍然清楚
- [ ] 視需求再加入 PWA 安裝功能

## 第四階段：單人內容

- [ ] 增加數字包與挑戰關卡
- [ ] 增加 AI 難度
- [ ] 增加不同下注個性的 AI
- [ ] 增加特殊計時模式
- [ ] 增加牌池限制等挑戰規則

角色、技能、道具和 Roguelite progression 暫不列入近期規劃。

## 版本推進條件

每個階段開始前，前一階段應符合以下條件：

- 自己能完整玩完一場。
- 幾位不熟悉規則的玩家能在沒有口頭協助下完成一場。
- 核心規則與主要流程有自動化測試保障。
