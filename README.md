# Air Poker

Air Poker 是一款以撲克牌解題為核心的單機對戰遊戲。

每局開始時，你會從自己的五張目標數字中選出一張，再從一副共用的 52 張牌裡挑出五張牌，讓點數總和剛好符合目標。找到解答只是第一步：你還要在限時內組出夠強的牌型，判斷對手的牌力，並決定要不要用 BIOS 把底池撐大。

用過的牌會留在牌桌上，但之後再拿來提交就會讓牌組失效。五局之間，牌池會越來越緊，早一局的選擇可能直接影響後面的解法。這讓 Air Poker 同時有數字調度、限時解題和下注心理戰三種節奏。

## 遊戲怎麼玩

一場對局最多五局，每局依序進行：

1. 雙方選擇本局要使用的目標數字。
2. 在倒數時間內，私下從 52 張牌中組出五張牌。
3. 鎖定牌組後，進行過牌、下注、跟注、加注或棄牌。
4. 進入攤牌，檢查牌組是否有效並比較牌型。
5. 結算 BIOS，更新已使用的牌，準備下一局。

如果雙方同時提交無效牌組，會保留原本的數字和牌池，重新進行一次組牌。若雙方選到同一張牌，還會觸發牌張衝突，讓勝負多一層風險。

## 目前版本

這是桌面瀏覽器原型，目前提供一人對電腦的完整五局對戰。內容包含：

- 教學、標準對局與不同計時設定
- 目標數字選擇、限時組牌與牌型判定
- BIOS 下注、加注、跟注與棄牌
- 牌張使用狀態、牌張衝突與無效牌組重選
- 自動儲存、續玩、對局結果與完整重播
- 重播匯入／匯出，以及本機保存的對局紀錄

所有資料都留在瀏覽器的 `localStorage`，不需要帳號，也不會傳送到遠端服務。

## 開始遊玩

需要 Node.js 與 npm。

```bash
npm install
npm run dev
```

接著開啟終端機顯示的網址。建議使用 1280×720 以上的桌面視窗，最低支援 1024×768。

## 開發指令

```bash
npm run typecheck  # TypeScript 檢查
npm test           # 單元測試
npm run build      # 建立正式版本
npm run test:e2e   # Playwright 瀏覽器測試
```

## 技術

專案使用 React、TypeScript、Vite 與 Tailwind CSS。遊戲規則集中在可測試的 TypeScript 引擎中，畫面只負責呈現狀態與傳送玩家操作；解題器則透過 Web Worker 執行，避免計算時卡住介面。
